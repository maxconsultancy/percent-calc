## Code of Conduct
By participating in this project, you agree to abide by our Code of Conduct. Please be respectful and inclusive in all your interactions.

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub issues. When creating a bug report, please include:
- A clear, descriptive title.
- Steps to reproduce the bug.
- Expected vs. actual behavior.
- Screenshots if applicable.

### Suggesting Enhancements
We welcome new ideas! If you have a feature request:
1. Check if the idea has already been suggested in the **Issues** tab.
2. If not, open a new issue and describe the feature and why it would be useful.

### Your First Code Contribution
1. **Fork** the repository to your own account.
2. **Clone** your fork locally: `git clone https://github.com`.
3. Create a new **branch** for your changes: `git checkout -b feature/amazing-feature`.
4. Make your changes and **commit** them with a clear message: `git commit -m 'Add amazing feature'`.
5. **Push** to your fork: `git push origin feature/amazing-feature`.
6. Open a **Pull Request** (PR) against the original repository.

## Style Guides
- **HTML/CSS:** Use 2-space indentation.
- **JavaScript:** Follow standard Vanilla JS conventions. Ensure the code is clean and commented where necessary.
- **Commits:** Use the imperative mood in subject lines (e.g., "Add feature" instead of "Added feature").

Thank you for your contribution! 🎉
