A sleek, responsive web application for quick percentage calculations. Built with **Vanilla JavaScript**, **CSS3**, and **HTML5**.

## ✨ Features
- **Instant Calculation:** Get results as soon as you hit the button.
- **Dark Mode:** Easy on the eyes with a toggleable theme.
- **Persistent History:** Saves your last 5 calculations using `localStorage`.
- **Individual Deletion:** Remove specific entries from your history list.
- **PDF Export:** Download your calculation history as a PDF file.
- **Mobile Friendly:** Fully responsive design for any screen size.

## 🛠️ Tech Stack
- **HTML5/CSS3** (Variables used for themes)
- **JavaScript** (ES6+ logic)
- **[jsPDF](https://github.com):** For generating PDF reports.
- **[Font Awesome](https://fontawesome.com):** For clean UI icons.
